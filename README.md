# Cybersecurity SOC Portfolio

Hands-on cybersecurity portfolio focused on Security Operations, Blue Team operations, security monitoring, log analysis, SIEM, detection engineering, threat intelligence, and incident response.

## About

This repository documents my practical journey toward becoming a Junior SOC Analyst / Security Operations Analyst.

The projects are based on hands-on labs and simulated security scenarios in controlled environments.

## Projects

### 01 — SOC Home Lab

Building and documenting a controlled cybersecurity lab environment for security monitoring and investigation.

### 02 — Windows Event Log Investigation

Analyzing Windows Security Event Logs, authentication events, logon types, and event correlation.

### 03 — Brute Force Investigation

Investigating failed authentication attempts and identifying potential brute-force behavior.

### 04 — Nmap Scan Detection

Analyzing network scanning activity and identifying reconnaissance patterns.

### 05 — Wireshark Investigations

Analyzing network traffic and investigating suspicious network activity using Wireshark.

### 06 — Suspicious PowerShell

Investigating PowerShell execution, process activity, command lines, and potential abuse.

### 07 — DNS Investigation

Analyzing DNS queries and investigating suspicious domains and DNS-based indicators.

### 08 — Phishing Investigation

Analyzing phishing emails, URLs, domains, headers, and indicators of compromise.

### 09 — Microsoft Sentinel

Building a cloud-based SIEM lab using Microsoft Sentinel and investigating security telemetry.

### 10 — KQL Detection Rules

Creating and testing KQL queries and detection rules for security monitoring.

### 11 — Full SOC Incident

End-to-end simulated SOC investigation combining detection, investigation, correlation, threat intelligence, MITRE ATT&CK, response, and documentation.
