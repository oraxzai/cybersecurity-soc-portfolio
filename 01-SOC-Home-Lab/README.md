# SOC Home Lab

## Objective

Build a practical home cybersecurity lab to simulate a Security Operations Center (SOC) environment and practice security monitoring, log analysis, investigation, and incident response.

## Lab Environment

* Host Machine: MacBook Air
* Virtualization: VMware
* Operating System: Windows VM
* Primary Tool: Windows Event Viewer
* Log Source: Windows Security Event Logs

## Lab Architecture

```text
MacBook Air
     |
   VMware
     |
 Windows VM
     |
Windows Security Logs
     |
 SOC Investigation
```

## Skills Practiced

* Windows Security Event Logs
* Authentication monitoring
* Event correlation
* Security investigation
* Basic incident analysis
* SOC analyst workflow

## SOC Investigation Workflow

```text
Event
  ↓
Alert
  ↓
Investigation
  ↓
False Positive / Suspicious Activity
  ↓
Incident
  ↓
Response
  ↓
Documentation
```
